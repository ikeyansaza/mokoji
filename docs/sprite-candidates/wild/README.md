# 成体 ワイルド系（ムフロン・ビッグホーン）— 候補と採用結果

ムフロン（`ADULT_MOUFLON`）とビッグホーン（`ADULT_BIGHORN`）の、顔・胴・角の見た目の検討の記録。
最終的に採用した形は `sprites.py` に入っている。ID は `candidates.txt` の絵の名前と同じ。

## 経緯

- 実物のムフロンは黒ではなく、栗色（赤茶）の体に、口まわり・腹・脚が白っぽく、オスは脇腹に淡い斑（サドルパッチ）がある。
  ビッグホーンは灰褐色で、口まわりとお尻が白い。今の絵はベタ塗りを「濃い色」と読むので、白抜きで実物の特徴を出した。
- ムフロン: 脇腹の斑（SADDLE）は頬紅に見えたので没。腹（BELLY）・脇腹の下寄り（LOWFLANK）も外し、背の帯（BAND）を採用した。
- ビッグホーン: ムフロンより明るい灰褐色を、胴の市松（DITHER）で表した。
- 鼻まわりは白抜き（M2: 鼻を 1 マス残す / M1: 鼻を 3 マス残す）。ムフロンは M2、ビッグホーンは M1 を採用した。
- 顔は、実物のほうが細長いので、左右の縁を内側へ寄せた。ムフロンは 1 段階（SLIM1）、ビッグホーンは 2 段階（SLIM2）。
- 角長版（角が伸びた姿）の角は、中の空洞を大きく、横へ広げた C 字にした。横は画面の左端（col 0）まで使っているので、
  縦を低くして（row 4〜9）横に広げた。ムフロンは細め（W2）、ビッグホーンは太め（W1）。
  縦に伸ばした案（上へ広がる）は、横に広げたかったので採らなかった。
- 角長版のムフロンは、以前は体ごと 1 行下げていた（角を高く伸ばすため）。新しい角は通常版と同じ高さに収まるので、
  体を下げなくなり、足元は通常版と同じ row 20 になった。
- 通常版の角は、小さな巻き角のまま。

## 実際の見た目で確認する

1. `candidates.txt` の中身を、`oled_preview.html` の左の貼り付け欄に貼って parse する。
2. 貼った候補は「pasted sprites」に出る。クリックすると OLED シミュレータで確認できる。
3. 採用済みの形は、同じページのツリー（evolution tree）にゲーム本体のスプライトとして出る。

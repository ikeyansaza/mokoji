# ハンプシャーの見た目 — 候補と採用結果

サフォーク系の成体 HAMPSHIRE（サフォーク系で feed と pet を両方多くしたときに進化する強化版）の見た目の検討の記録。
kurohitsuji.svg を元にした「黒い羊」のテイストで、4 案を描いて比べた。採用した形は `sprites.py` の
`HAMPSHIRE` に入っている。ここには、採用しなかった案も含めて残してある。

## 案の一覧

| 案 | 名前（sprites.py にあったときの名前） | 特徴 | 状態 |
|---|---|---|---|
| A | `HAMPSHIRE_DITHER` | ディザリング（千鳥模様で「暗い色」を擬似） | 未採用 |
| B | `HAMPSHIRE_OUTLINE` | 体の輪郭だけ（中身を空にして「シルエット」感） | 未採用 |
| B2 | `HAMPSHIRE_OUTLINE2` | 輪郭と、中央に小さなバンプ（あなたの案・毛束っぽい） | 採用: ADULT_HAMPSHIRE |
| C | `HAMPSHIRE_STRIPES` | 縦縞（毛並みのテクスチャ） | 未採用 |

## 既知の課題

- 増毛期の `ADULT_HAMPSHIRE_FLUFFY` は、採用中の B2 ではなく、基本の羊 `HITSUJI` に毛と暗い脚を足して作っている。
  そのため、`oled_preview.html` のツリーで並べると、通常版のハンプシャーとは別の見た目になる。
  `ADULT_SUFFOLK_FLUFFY` も同じ作り。

## 実際の見た目で確認する

1. `candidates.txt` の中身を、`oled_preview.html` の左の貼り付け欄に貼って parse する。
2. 貼った候補は「pasted sprites」に出る。クリックすると OLED シミュレータで確認できる。
3. 採用済みの形は、同じページのツリー（evolution tree）にゲーム本体のスプライトとして出る。

## 元素材について

スプライトの元素材は dot-illust.net 由来（非商用のみ可）。IP 展開・商用化の際は、オリジナルに差し替える。

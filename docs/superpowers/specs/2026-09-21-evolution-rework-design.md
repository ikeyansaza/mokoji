# 進化ルールの見直しと、若羊・成体のスプライト更新

## 目的

- 進化を、世話の傾向スコア（なでる・毛刈り・角研ぎの回数）に頼らず、プレイヤーが画面で見ている「空腹」と「幸福」の値と、乱数で決める。
- 毛・角の世話（毛刈り・角研ぎ）を、成体の段階だけにする。若羊の段階は、ベビーと同じ操作にする。
- 毛が伸びたときのキラキラを止め、増毛版の見た目の毛を大きくする。
- 若羊 3 種と成体 3 種の絵を、新しいものに差し替え、成体の足を新しい形にそろえる。
- MERINO は、一旦、進化先から外す。

## 決定事項

| 項目 | 決定 |
|---|---|
| 進化の判定に使う値 | 進化のときの `hunger`（空腹バーの値。高いほど満腹）と `happy`（幸福バーの値）。残りは乱数 |
| 世話の傾向スコア | 進化に使わない。`tend_*` のメンバを Game から削除し、セーブには 0 を書く |
| セーブ形式 | 変えない（`GameSaveData` の構造と `MAGIC` は、そのまま）。読み込むとき、`tend_*` は無視する |
| 毛・角の伸び | 成体だけ。若羊は伸びない。若羊 → 成体で 0 に戻す |
| 毛刈り・角研ぎ | 成体だけ。若羊のメニューはベビーと同じ 5 項目（ごはん・なでる・ゲーム・プロフ・もどる）。成体は 6 項目 |
| 増毛のキラキラ | 止める。`drawWool` の呼び出しと関数を削除する |
| MERINO | 進化先の抽選から外す。`Breed::MERINO`・絵・増毛版は残す（既存のセーブは表示できる） |

（後日の変更: 絵と増毛版も、ゲームのスプライトから外して、`docs/sprite-candidates/merino/` の没候補に移した。`Breed::MERINO` は残し、古いセーブの MERINO は CORRIEDALE の絵で表示する。）
| 足 | 成体の足を、row 19 の棒 + row 20 の 2 本の形に。成体の足元は row 20（`MOUFLON_LONGHORN` は体が 1 行低いので row 21）。ベビー・若羊は row 19 のまま |
| 増毛版の見た目 | 体の外周の毛を、今の 1px から大きくする。候補を並べて、選んでもらう |
| PR | 1 本にまとめる。コミットは、絵 → ルール → 増毛の順に分ける |

## 進化のルール

`hunger`・`happy` は 0〜100。重みの係数（0.4 / 0.5）は、定数にして調整しやすくする。

**ベビー → 若羊（3 日）**

| 系統 | 重み |
|---|---|
| モコ系 | `50 + hunger × 0.4`（満腹なほど） |
| サフォーク系 | `50 + happy × 0.4`（幸福なほど） |
| ワイルド系 | `50 + (200 − hunger − happy) × 0.2`（どちらも低いほど。これまでの「放置気味」の狙いを引き継ぐ） |

**若羊 → 成体（7 日）**

| 系統 | 品種と重み |
|---|---|
| モコ系 | CORRIEDALE `50`、LINCOLN `50`（MERINO は抽選に入れない） |
| サフォーク系 | SUFFOLK `50`、HAMPSHIRE `50 + happy × 0.5` |
| ワイルド系 | MOUFLON `50`、BIGHORN `50 + hunger × 0.5` |

## 毛・角と、メニュー

- `tick()` の毛・角の伸びは、`_stage == ADULT` のときだけ。ベビー・若羊では伸ばさない。
- ベビー → 若羊、若羊 → 成体の進化で、`_wool` と `_horn` を 0 にする（古いセーブの若羊に毛が溜まっていても、成体が毛だらけで始まらない）。
- メニューの項目数と並びは、ベビーと若羊で同じ 5 項目（毛刈り・角研ぎの枠を出さない）。若羊 → 成体で、項目が 5 → 6 に変わるので、メニューのカーソルを先頭に戻す（今のベビー → 若羊で 4 → 5 に変わるときと同じ扱い。ベビー → 若羊では項目数が変わらなくなるので、リセットは若羊 → 成体だけになる）。
- 毛刈り・角研ぎの効果（毛・角を 0 に戻し、幸福度 +10、効果音）は、変えない。傾向スコアの加算だけ消す。
- 毛が伸びたときの増毛版への切り替え（`isFluffy`: `_wool > 50`）と、角長版（`isLonghorn`）は、変えない。

## スプライト

- **差し替え**: `YOUNG_MOKO`・`YOUNG_SUFFOLK`・`YOUNG_WILD`・`ADULT_SUFFOLK`・`ADULT_MOUFLON`・`ADULT_BIGHORN` を、貼ってもらった絵に。`YOUNG_SUFFOLK` の row 12 は 23 文字なので、左右対称になるよう `......##.......##.......` に直す。
- **足**: 貼ってもらった 3 種の足（row 19 の棒 + row 20 の 2 本）と同じ形を、他の成体（メリノ・コリデール・リンカーン・ハンプシャー・角長 2 種）にも作る。棒の幅は、ムフロン系（8px）とビッグホーン系（7px）に合わせる。増毛版は、通常版から作られるので、自動でそろう。
- **足元のテスト**（`test_sprite_baseline.py`）: ベビー・若羊は row 19、成体は row 20、`MOUFLON_LONGHORN` は row 21。
- **増毛**: `_halo` の毛を大きくする。候補（2px など）を並べて、選んでもらう。
- **docs**: `docs/sprite-candidates/` の記録を、実際のスプライトに合わせて更新する（採用案が実際の絵と一致するテストがあるため）。差し替えた絵の旧デザインは、旧デザインとして残す。

## テスト方針

- **進化**: 重みを、乱数と切り離した純粋関数（`youngChoices` / `adultChoices` / `pickWeighted`）にして、空腹・幸福が高いとき・低いときの重みを直接確かめる。MERINO が出ないこと。範囲外の値（負・100 超）でも、重みが範囲内に収まること。抽選が、乱数の全範囲を使うこと（今は 0〜127 しか使わず、最後の選択肢が選ばれにくい）。
- **毛・角**: 若羊で伸びないこと。成体で伸びること。進化で 0 に戻ること。若羊のメニューがベビーと同じ 5 項目であること。
- **セーブ**: 読み込み → 保存で、構造とサイズが変わらないこと。古いセーブ（`tend_*` が非 0、若羊で毛が溜まっている）が読めること。
- **スプライト**: 足元、左右対称、増毛版が通常版を含むこと（既存のテストを、新しい足元に合わせて更新）。

## 対象外

- MERINO の完全削除（今回は進化先から外すだけ）。
- ハンプシャー以外の成体の絵の描き直し（足だけをそろえる）。
- 実機の見た目の確認（ASCII とテストまで。実機は、書き込んで確認する）。

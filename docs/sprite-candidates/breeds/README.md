# 品種の案（進化先に採用しなかった）

進化先は、3 系統 × 2 品種の 6 品種（コリデール・リンカーン・サフォーク・ハンプシャー・ムフロン・ビッグホーン）にしている。
それ以外の品種の絵を、成体のサイズで描いた案を、没候補として残す場所。品種を増やすとき、新しい系統を考えるときの出発点にする。

## 経緯

- あなたが描いた、成体の絵の案 13 種。どれも、今の成体と同じ体（row 10〜20）に、頭・角・毛の違いだけを付けている。
- 進化のルールは、空腹・幸福の値と乱数で 3 系統から 2 品種ずつを選ぶ形なので、どの案も、今は進化先に入れていない。
- ゲームのスプライト（`sprites.py`）には入っていない。`Breed` にも、対応する値はない。

## 採用するとき

- 進化先に加えるときは、`Game::Breed`（`game.h`）に品種を足し、`youngChoices` / `adultChoices` の重みと、`display.cpp` の絵の選択、
  `sprites.py` と `sprites_gen.py` の `SPRITE_NAMES` に足す。セーブの値（`Breed` の生値）が増える点に注意する。
- 絵は `_L`（左向き）と `_R`（`_L` の左右反転）が必要。増毛版・角長版が要るかは、系統による。

## 実際の見た目で確認する

1. `candidates.txt` の中身を、`oled_preview.html` の左の貼り付け欄に貼って parse する。
2. 貼った候補は「pasted sprites」に出る。クリックすると OLED シミュレータで確認できる。

## 元素材について

スプライトの元素材は dot-illust.net 由来（非商用のみ可）。IP 展開・商用化の際は、オリジナルに差し替える。

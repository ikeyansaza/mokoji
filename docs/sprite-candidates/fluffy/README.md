# 増毛（ADULT_*_FLUFFY）— 候補と採用結果

特殊成長の増毛期（モコ・サフォーク系）の見た目の検討の記録。増毛版は、通常版の絵に毛を足した形にする。
最終的に採用した形は `sprites.py` の `_halo` に入っている。ここには、採用しなかった案も含めて残してある。

## 経緯

- 従来の増毛版は、体から離れた縦の棒を、画面の左右の端（col 0〜1、22〜23）に足していた。毛が体につながっておらず、
  毛というより画面の端の線に見えた。
- サフォーク・ハンプシャーの増毛版は、通常版ではなく基本の羊 `HITSUJI` から作られていて、通常版と別の絵だった。
- 従来の毛は、幅 24 の中央（col 11.5）で対称に足していて、スプライトの軸（col 11）と半ピクセルずれていた。
- 体の外周の輪郭から毛を自動で足す方法で、4 案（F1〜F4）を作って比べた。各行の左右の端を検出して外側に足すので、
  毛は必ず体につながり、どの品種にも同じ方法で適用できる。
- 採用は F3（HALO）。MERINO の顔を覆う案（C1〜C3）も試したが、顔は覆わないことにした。

## 採用の内容

5 品種（MERINO・CORRIEDALE・LINCOLN・SUFFOLK・HAMPSHIRE）すべてを、それぞれの通常版に F3（HALO）を足した形にした。
毛は体（row 10〜17）の左右の端の外側に 1px。耳（row 9）と足元には足さない。毛の量は、従来は MERINO だけ多めだったが、
全品種が同じ量（1px）になった。

## 設計の決まり

`test/test_sprites.py` が、増毛版について次を検証している。

- 通常版の絵をすべて含むこと（別の絵から作らない）。
- 毛が増えていること。
- 毛が体から浮いた塊を作らないこと（毛が耳・腕などをつなげるのは構わない）。
- 通常版の行が左右対称なら、増毛版も左右対称であること。

## 実際の見た目で確認する

1. `candidates.txt` の中身を、`oled_preview.html` の左の貼り付け欄に貼って parse する。
2. 貼った候補は「pasted sprites」に出る。クリックすると OLED シミュレータで確認できる。
3. 採用済みの形は、同じページのツリー（evolution tree）にゲーム本体のスプライトとして出る。

## 元素材について

スプライトの元素材は dot-illust.net 由来（非商用のみ可）。IP 展開・商用化の際は、オリジナルに差し替える。

# 若羊（モコ系・サフォーク系）— 候補と採用結果

若羊の 3 系統のうち、モコ系とサフォーク系の見た目の検討の記録。ワイルド系の若羊は、この検討の対象外
（角の検討は [../horn/](../horn/) にある）。最終的に採用した形は `sprites.py` に入っている。

## 経緯

- モコ系の若羊は、row 7 が左右対称の軸（col 11）から 1px 右へずれて、絵が崩れていた。
- サフォーク系の若羊は、モコ系とほぼ同じ絵だった（違いは、崩れていた row 7 だけ）。系統の違いがわからなかった。
- モコ系は、崩れを直すために、サフォーク系の絵をそのままコピーした（M0）。
- サフォーク系は、モコ系とは別の「サフォークらしい」絵にするため、候補（S1・S2、A〜C）を出した。最終的には、
  あなたが描いた、体を輪郭だけにした案（D）を採用した。成体 `SUFFOLK` と同じ作りで、系統がつながって見える。
- あわせて、モコ系の若羊の足元（row 17）を、他のフォームと同じ row 19 にそろえた。ゲームはスプライトを固定位置に
  2 倍で描くので、足元が 2 行違うと、進化のたびに羊が画面で 4px 上下にずれて見えるため。

## 採用の割り当て

| スプライト | 案 | 特徴 |
|---|---|---|
| YOUNG_MOKO | M0 | 頭の毛玉あり・顔は見える。足元は row 19 |
| YOUNG_SUFFOLK | D | 体は輪郭だけで、顔のディテールは無い。成体 SUFFOLK と同じ作り |

## 設計の決まり

`test/test_sprites.py` が、若羊の 3 系統について次を検証している。

- 左右対称であること（対称軸は col 11。最後の行のひづめは全フォーム共通で元から非対称なので除く）。
- 3 系統の絵が、互いに違うこと。

`test/test_sprite_baseline.py` が、全フォームの足元が row 19 であることを検証している（意図した例外は
`MOUFLON_LONGHORN` の row 20 だけ）。

## 候補の一覧

「状態」の見方: 採用 = `sprites.py` に反映済み / 未採用 = 候補として残してある。

| ID | 特徴 | 状態 |
|---|---|---|
| M0 | サフォーク若羊の旧デザインをそのままコピー（頭の毛玉あり・顔は見える） | 採用: YOUNG_MOKO |
| M1 | 毛が顔の両脇を覆う。元のデザインの意図を残して、中心（col 11）にそろえ直した | 未採用 |
| M2 | M1 に、頭の上の毛玉を足す | 未採用 |
| S0 | サフォーク若羊の旧デザイン（モコ系とほぼ同じ絵） | 旧デザイン（M0 として、モコ系が引き継いだ） |
| S1 | 旧デザインの顔をディザで「うっすらグレー」にする | 未採用 |
| S2 | 旧デザインの顔を黒くする（ハンプシャーの予兆） | 未採用 |
| A | 頭の毛玉をなくし、黒い顔（目は細く）にする | 未採用 |
| B | A に、横に張った大きな耳を足す | 未採用 |
| C | 頭の毛玉をなくし、顔をうっすらグレー（ディザ）にする | 未採用 |
| D | 体を輪郭だけにした専用の絵（あなたが描いた案）。成体 SUFFOLK と同じ作り | 採用: YOUNG_SUFFOLK |

## 実際の見た目で確認する

1. `candidates.txt` の中身を、`oled_preview.html` の左の貼り付け欄に貼って parse する。
2. 貼った候補は「pasted sprites」に出る。クリックすると OLED シミュレータで確認できる。
3. 採用済みの形は、同じページのツリー（evolution tree）にゲーム本体のスプライトとして出る。

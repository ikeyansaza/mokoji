# 耳の横の角 — 候補と採用結果
ワイルド系（YOUNG_WILD / MOUFLON / BIGHORN と、角長期の MOUFLON_LONGHORN / BIGHORN_LONGHORN）の
角のデザイン検討の記録。最終的に採用した形は `sprites.py` に入っている。ここには、採用しなかった案も含めて
残してある。別の系統や新しい品種の角を考えるときの出発点にする。

## 経緯

- 最初は、頭のてっぺんの上に 1px の細い線で角を描いていた。頭とほぼつながっておらず、角ではなく飾りに見えた。
- 頭上へ高く伸ばすと大げさになるため、**耳の横に巻く形**へ変更した。
- 初期案 A / B / C から、頭の横で 1 巻きする B を選んだ。B を土台に、丸み・先端の形・大きさを変えた
  10 案（B01〜B10）を作って比べた。
- MOUFLON と BIGHORN が似て見えたため、BIGHORN は横に広い B09 にして差をつけた。BIGHORN_LONGHORN は
  B09 の側面を伸ばして先端を跳ねさせた B09F にした。

## 採用の割り当て

| スプライト | 角 | 特徴 |
|---|---|---|
| YOUNG_WILD | B04 | 頭に寄り添う小さな巻き |
| MOUFLON | B01 | 底を丸めた標準の 1 巻き |
| MOUFLON_LONGHORN | B06 | 先端が外へ跳ねる。体が 1 行下にずれているので、角も 1 行下げて使う |
| BIGHORN | B09 | 横に広い平らな弧 |
| BIGHORN_LONGHORN | B09F | B09 の側面を伸ばして先端を跳ねさせる |

## 設計の決まり

`test/test_sprites.py` が次の 3 点を検証している。新しい角を描くときも守る。

- 角は頭・耳と 1 つの塊としてつながる（4 近傍。1px の斜め接触だけでは不可）。
- 左右対称（対称軸は col 11）。
- 頭のてっぺんより 1 行を超えて上へ突き出さない。

テストでは見ていないが、描くときの指針として、太さは 2px 以上にする（1px の細い線だと、角に見えなかった）。

## 候補の一覧

「状態」の見方: 採用 = `sprites.py` に反映済み / 未採用 = 候補として残してある / 外した = 一旦外した。

| ID | 特徴 | 状態 |
|---|---|---|
| A | 耳の上に小さく巻く | 初期案・未採用（見立て: 小さすぎて、耳が太くなっただけに見える） |
| B | 頭の横で 1 巻き | 初期案・これをベースに B01〜B10 へ展開 |
| C | 耳をぐるっと囲む大きな巻き | 初期案・未採用（見立て: 角として読みやすいが、頭が横長になる） |
| YOUNG_BUD | 耳の上の小さな出っ張り（YOUNG_WILD 用の芽） | 初期案・未採用（見立て: 頭が横に広がるだけで、芽に見えない） |
| B01 | 底の外側角を落として、内へ巻く | 採用: MOUFLON |
| B02 | 上下とも斜めに落とした小さめの円 | 外した（B01 と大差なし） |
| B03 | 上の弧を 3px に太くして丸みを強調 | 未採用（BIGHORN の一時候補） |
| B04 | 頭に寄り添う小さな巻き（頭頂より上に出ない） | 採用: YOUNG_WILD |
| B05 | 先端が内側（顔側）へ鉤状に曲がる | 未採用 |
| B06 | 先端が外側へ跳ねる（羊の角らしい反り） | 採用: MOUFLON_LONGHORN（1 行下げて使用） |
| B07 | B を 1 行下げて、頭頂より上に出ない | 外した（弧が頭の幅に溶け込む） |
| B08 | 上の頂点を 1px にした尖り円 | 外した（B01 と大差なし） |
| B09 | 横に広い平らな弧（頭が横に大きくなる） | 採用: BIGHORN |
| B10 | 先端が 2px から 1px に細くなる | 未採用 |
| B09F | B09 の側面を 1 行伸ばし、先端を外へ跳ねさせる（B06 の反りを B09 に移植）。耳とつなげるため row 8 に 1px 足してある | 採用: BIGHORN_LONGHORN |

## 実際の見た目で確認する

1. `candidates.txt` の中身を、`oled_preview.html` の左の貼り付け欄に貼って parse する。
2. 貼った候補は「pasted sprites」に出る。クリックすると OLED シミュレータで確認できる。
3. 採用済みの形は、同じページのツリー（evolution tree）にゲーム本体のスプライトとして出る。
